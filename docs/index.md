# Churn Prediction Pipeline

**From messy CSV to production on AWS. Free, hands-on, no signup required.**

Start with a dirty dataset. End with a production ML pipeline on SageMaker, with LLMs where they actually make sense. Every module is a real notebook you can read here or run yourself.

## How it works

1. Read any lesson in the sidebar. Full code and outputs are rendered on this site.
2. Want to run it? Hit the **Open in Colab** badge at the top of each notebook, then *File → Save a copy in Drive*.
3. Each module is self-contained and replays previous steps, so you can start anywhere.

## What you'll build

A working system that takes any client's raw CSV, cleans it, engineers features, trains an XGBoost model behind proper evaluation gates, produces scored predictions with risk tiers and plain-English explanations via Amazon Bedrock, monitors for drift, and deploys on SageMaker Pipelines.

**Stack:** Python 3.11+, pandas, scikit-learn, XGBoost, SHAP, SageMaker, S3, Bedrock (Claude), MLflow.
